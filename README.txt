2. Actions tab -> "Build PvpBot with Crystal PvP" -> Run workflow.
3. Download artifact PvpBot-crystal, unzip, replace the plugin jar, restart.
Bots need obsidian + end crystals (+ a sword) in their inventory (put them in kits.yml).
Settings: crystal-pvp (default true), crystal-max-self-damage (default 8).
